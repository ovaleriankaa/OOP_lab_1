## Лабораторна Робота №1
Слободян Валерія Василівна
ІПС-32(ІС)
Варіант №10 - Таксопарк

## Основний функціонал
* **Завантаження даних:** Зчитування автомобілів (Business та Economy класів) із файлу `cars.csv`.
* **Обчислення вартості:** Підрахунок загальної вартості всіх автомобілів у парку.
* **Сортування:** Сортування авто за витратою палива.
* **Пошук:** Вибірка автомобілів, що відповідають заданому діапазону швидкості.

## Використано:
* **Мова:** Java 21
* **Збірка:** Maven
